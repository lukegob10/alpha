**Material remaining gaps**

**G1 — P2: Compactor overflow goes directly to truncation or exhaustion instead of adapting the summary input.**

Trigger: the history selected for summarization exceeds the summarizer's actual input allowance, particularly after selecting a small-context model or receiving a large newest tool transaction. Alpha converts the entire chosen prefix and invokes one summary stream (`src/core/condense/index.ts:1082`, `:1117`). A context-window error flows to one truncation fallback (`src/core/context-management/index.ts:577`, `:645`); fallback refuses a newest complete step that cannot fit (`:269`). Manual compaction reports the error and returns (`src/core/task/Task.ts:11763`). This protects stored history and transaction integrity, but a recoverable oversized summary request can stop work or hide middle history without producing a summary.

Codex locally retries after removing an oldest history item (`codex-rs/core/src/compact.rs:358`); its remote path can replace oversized tool outputs with an explicit truncated-output placeholder while preserving call identity, output success, and metadata (`codex-rs/core/src/compact_remote_history.rs:83`, `:157`, `:222`). The local contract is explicitly tested at `codex-rs/core/tests/suite/compact.rs:4367`.

Minimum convergence change: bound a request-only reduction policy for summarizer input under the existing deadline. Prefer shrinking eligible tool-output bodies with a clear placeholder and complete call/result structure; retain the authoritative original archive and user instructions. Allow a small fixed number of measured retries before the existing safe fallback. This is a convergence enhancement, not a reason to weaken Alpha's exact-tail or no-progress checks.

Minimum regression: a deterministic provider rejects the first oversized summary request and accepts the reduced retry; assert that the reduced summary is installed, original records and output statuses are unchanged in saved history, and cancellation or continued overflow never installs a partial result. Current tests establish safe fallback/exhaustion, not adaptive summary retries.

**G2 — P2: Previous-model compaction continuity is limited to a live in-memory handler.**

Trigger: select a smaller model after a larger-model task, then reload before compaction, receive a transient summary failure, or encounter a retired/unavailable previous model. Alpha retains `previousCompactionHandler` only while applying a live configuration change (`src/core/task/Task.ts:10519`); it uses that handler only if the old window is larger (`:10540`) and releases/clears it after the attempt (`:10554`). Summary provider failures return a no-progress response (`src/core/condense/index.ts:1097`, `:1205`). The existing test verifies a live old-model summary and selected-model replacement budget (`src/core/condense/__tests__/request-isolation.spec.ts:52`), but there is no reconstruction or selected-model summary retry in this path.

Codex restores previous turn model settings before downshift compaction (`codex-rs/core/src/session/turn.rs:1429`) and its OpenAI remote path retries eligible old-model failures with the current model (`codex-rs/core/src/compact_model_fallback.rs:10`; `codex-rs/core/src/compact_remote_v2_installation.rs:137`). Tests cover unavailable/renamed old models and downshift after resume (`codex-rs/core/tests/suite/compact.rs:2866`, `:3007`, `:3852`). Compaction compatibility hashes are additionally meaningful for providers supplying opaque checkpoints; Alpha has no equivalent provider capability/hash contract today, so that part is recorded as a conditional delta below.

Minimum convergence change: persist only the stable prior model/provider routing identity needed to reconstruct an authorized compactor on resume; keep credentials and authority host-owned. Preserve existing policy snapshots. If the previous compactor is unavailable, attempt one bounded selected-model summary after request-only input reduction, excluding cancellation and incomplete-summary outcomes from fallback.

Minimum regression: save a large-model task, switch to a smaller model, reload, and have the previous model reject with model-not-found. Assert the selected model receives a fitting summary request, original transcript is retained, and the next normal request fits the selected model. Also cover cancellation, partial summary, missing previous routing identity, and two consecutive failed attempts.

**Intentional and optional differences**

- Alpha's global percentage threshold, reserved output tokens, 10% safety buffer, measured reduction requirement, bounded exact suffix, and non-destructive rewind archive are native extension policies. They serve the same behavioral goals without reproducing Codex storage architecture. They are not score penalties.
- Current Codex OpenAI/Azure capability defaults enable remote V2 compaction (`codex-rs/model-provider/src/capabilities.rs:31`); it accepts one opaque compaction item and persists the checkpoint/model hash (`codex-rs/core/src/compact_remote_v2.rs:375`, `:464`; `codex-rs/core/src/compact_remote_v2_installation.rs:238`). Alpha has a local text-summary abstraction with provider-neutral continuation instead (`src/core/condense/index.ts:865`; `src/api/index.ts:100`). This is a provider-specific capability delta, excluded from the behavioral score because local compaction already provides safe continuation. If remote checkpoints are added, version compatibility/model hashes and provider-state replay become mandatory adapter contracts.
- Codex's speculative async compaction is `UnderDevelopment` and default-off (`codex-rs/features/src/lib.rs:2120`); the implementation checks history generation, model, auth owner, and shutdown ownership (`codex-rs/core/src/session/async_compaction.rs:40`, `:83`, `:165`, `:199`). Alpha serializes summarization at a safe boundary. Async preparation is an optional latency opportunity, excluded from this score; no speed claim is made.
- Codex's optional token-budget reset/fallback-prompt lane and default-off client-retained output/developer-message experiments were not used as mandatory parity requirements.
