# Release 3.2.0 disposal and storage cleanup

The October 16, 2026 PR CI failures were ENOTEMPTY errors while removing temporary task storage. Direct completed-job logs identify all seven prior Windows failures, ten subsequent Windows failures and three macOS failures as this cleanup error. Linux passed. Native assertions and configured test deadlines are retained.

TaskHistoryStore.dispose previously launched its final index flush without returning a completion boundary. AlphaProvider disposal could finish while safeWriteJson was still creating the tasks directory or its lock. Disposal now returns a coalesced promise, drains admitted history mutations before its final index snapshot, and lets provider disposal await it. Timer refreshes and explicit index flushes enter the same existing mutation queue before resolving storage paths, preserving the older dispose-then-flush calling pattern. Existing synchronous callers still start shutdown immediately and retain a background error observer. Awaiting owners receive the original failure, including null or undefined, and can explicitly retry.

Task command-output cleanup also resolved storage through a directory-creating helper even when no output existed. Cleanup should resolve an existing path without recreating storage. Directly constructed test Tasks must join their message-queue initialization before their fixture releases its storage; that startup boundary is separate from the model-loop termination join.

The current Codex reference is [openai/codex commit 6ae8b8aa7c608730d4315d59c5c081897ae02780](https://github.com/openai/codex/commit/6ae8b8aa7c608730d4315d59c5c081897ae02780), retrieved October 16, 2026. Its [task abort path](https://github.com/openai/codex/blob/6ae8b8aa7c608730d4315d59c5c081897ae02780/codex-rs/core/src/tasks/mod.rs#L944) awaits the owned abort callback and flushes interrupted history before publishing the terminal event. Its [abort lifecycle test](https://github.com/openai/codex/blob/6ae8b8aa7c608730d4315d59c5c081897ae02780/codex-rs/core/tests/suite/abort_lifecycle.rs#L53) holds a callback and verifies completion precedes the terminal event for interrupt and shutdown. Alpha applies that ownership principle through its existing TypeScript persistence and VS Code disposal boundaries. There is no Rust port or OS sandbox change.

Controlled promises cover an admitted per-task write, a suspended final index write, concurrent disposal callers, original failure propagation and an explicit retry. Provider tests independently hold the history-disposal boundary. The exact VS Code 1.125.0 gate and fresh platform CI remain release requirements. No additional model requests or live-sweep reruns are needed for this storage-lifetime correction.
