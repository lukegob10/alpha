# Alpha Code / Codex CLI divergence audit — 2026-10-11

Alpha's shared agent foundation is substantially aligned with Codex CLI. The active implementation already has a shared turn engine, immutable request context, a captured tool/policy surface, explicit outcomes, cancellation, durable tool transactions, multi-session routing, provider reasoning replay and bounded delegation. The next work should extend these owners. The most consequential gaps concern failed-history operations, command-rule boundaries, provider message fidelity, partial-stream recovery and integration completeness.

Read-only probes reproduced failed-save rewind acknowledgement, executable-name prefix approval, lost MCP tool pages and truncation on a valid empty resource cursor. Existing passing tests do not cover the full invariant in those cases. Other findings below distinguish source-proven differences, intentional contracts, optional upstream capabilities and unverified risks.

The practical target is behavioral alignment in Alpha's TypeScript/VS Code harness. Codex's OS sandbox, Rust architecture, terminal UI, desktop services and cloud infrastructure are excluded. Embeddings, native Alpha Tickets, scheduling, the HTML viewer and existing execution protections remain first-class Alpha capabilities.

**Reference and method.** Codex source was freshly cloned and pinned to [a07c8ebd57feedc4cf5dfe854c8e9101de54186b](https://github.com/openai/codex/commit/a07c8ebd57feedc4cf5dfe854c8e9101de54186b), committed 2026-10-11 12:38 UTC. Alpha HEAD was `b0423c06af2341c89948ec2a68f56ffd3e6f037a`; all current uncommitted changes were included. The initial snapshot contained 116 changed/untracked file paths. Those files were preserved. The review used the maximum available team: three sub-agents plus the primary reviewer, with workers reused for six domain passes; the primary reviewed Alpha-native additions and reconciled overlap. Production call sites, shared schemas and nearest tests were inspected on both sides. Historical Alpha design documents and feature names were not treated as behavioral proof.

**Meaning of the categories.** Close means the reviewed invariant is implemented and reachable; it does not mean every edge case is certified. Partial means an implemented surface has a specific behavioral difference. Missing means no corresponding active native capability was found in the inspected catalog/owners. Intentional means a documented or appropriate host/product adaptation that should be retained or deliberately reconsidered. Unknown means the evidence does not establish behavior or comparative performance. These classifications are not a measured overall parity percentage.

## Highest-priority concrete work

**P1 — Durable rewind settlement, 3–5 person-days.** `src/core/message-manager/index.ts:123–132,275–276` treats boolean save failures as artifact-cleanup decisions and still resolves successfully. `src/core/webview/webviewMessageHandler.ts:409–428` proceeds to publish deletion. A deterministic script using the current implementation and injected documented save receipts reproduced two-message histories becoming durable lengths 2/1 or 1/2 while both memory views had length 1. Nearest `index.artifacts.spec.ts:111` exercises false saves but asserts only artifact safety. Extend the owning persistence transition so failure/recovery/reload cannot acknowledge a partially committed rewind. Codex's coherent rollback reconstruction is the behavioral reference (`session/rollout_reconstruction.rs:131,317`; tests `rollout_reconstruction_tests.rs:582,733,837`).

**P1 — Executable/token command rules and explicit compatibility policy, 5–8 person-days.** A pure rule-decision reproduction found `getCommandDecision("git-impostor status", ["git"], [])` returns `auto_approve`. Alpha uses raw lowercased `startsWith` matching (`commands.ts:149–167`). Codex uses argv tokens and the strongest matching decision (`execpolicy/rule.rs:45–58`, `policy.rs:403`, `decision.rs:9–16`). Alpha's longer-allow-over-deny contract is explicitly documented (`webview-ui/src/i18n/locales/en/settings.json:324,326`); preserve readers for stored rules and deliberately choose whether that precedence remains. Do not silently reinterpret global saved rules. Cover quoting, executable boundaries, case semantics, chains and child authority; nearest tests `commands.spec.ts`, `commandApprovalAmendment.spec.ts`, `checkAutoApproval.spec.ts`.

**P2 — Complete MCP pagination and preserve empty cursors, 3–5 person-days.** `McpHub.ts:1027–1080` discards `tools/list.nextCursor`; initial resource/template caches also fetch one page. A two-page mock against the current method made one request and returned only `page_one_tool`. Model-facing resource traversal already exists, but `McpResourceTools.ts:77,93` and Hub request builders at `:1755,1774` treat empty-string cursors as absence. A second probe returned only the first resource with an empty cursor to page two. Reuse a bounded cancellable collector for catalog refresh, preserve explicit per-server paging, and test presence, repeats, caps, abort and reconnect. Upstream `codex-mcp/src/pagination.rs:39` and `pagination_tests.rs:16,44` establish bounded all-page/empty-cursor behavior. No discovery redesign is needed.

Upstream phase roundtrip/reload tests are `protocol/models.rs:2633` and `core/tests/suite/client.rs:1052,1134`. **P2 — Bound retained processes/sessions, 3–5 person-days.** Terminal reuse and session binding have cleanup, but no counterpart to Codex's soft cap/pruning policy. Define per-task/global admission, preserve unread receipts, report rejection/eviction and protect user-owned terminals.
