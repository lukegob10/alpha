Operator runbook · worked example

Check an offline document handoff

Before handing a colleague the sample design spec, check that they can open the copy in Alpha and see its layout illustration using only the files they receive.

Before you start

Use VS Code with Alpha installed and the handoff folder extracted outside the author’s workspace. In this example the packet contains spec.html and images/layout-sample.png. Keep the original packet available in case the copy is incomplete.

Check the recipient’s copy

  1. Open the extracted folder as the workspace. In Explorer, confirm spec.html is at the root and layout-sample.png is inside images. If either is missing, stop and ask the author for a complete packet.
  2. Preview the spec. Open the copied HTML and run Alpha: Preview HTML Document from the Command Palette. The sample opens with the heading beginning “A document belongs to a task” and the label “Proposed design”. If another document appears, check the selected folder and file before continuing.
  3. Inspect the figure under “Proposed ownership boundaries”. The wireframe shows a narrow left column and two panels beneath the wide panel on the right. A caption alone is insufficient. If the picture is missing, compare the file path with the image reference in the copied HTML. Have the author correct the packet, then repeat the checks on a fresh copy.

Record the handoff result

Mark the copy ready when both the expected spec and its illustration appear. Record the packet name and what you observed so the recipient can identify the checked copy. If a check fails, mark it blocked and give the author the failing step, file path and visible symptom.
